Ski Jumper

Direct link

A short, arcade-style game made in GameMaker about skiing down a slope and avoiding obstacles. All code for the game was done by me, all art for the game was done by Milo Beall. It was made for an itch.io game jam with the theme "jumping." Published November 22, 2019.
